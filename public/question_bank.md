# ACSES Technical Quiz - Syllabus & Question Bank Outline

## 1. First Year (FY) - Target: 300 Questions
* **Focus:** Transition from junior college to engineering.
* **Topics:** 
  * Basic Physics (Mechanics, Optics, Thermodynamics)
  * Basic Electronics (Capacitors, Resistors, Diodes, Logic Gates)
  * Introductory Tech (What is a CPU, Basic Internet Concepts, Intro to C programming logic)
* **Goal:** Keep difficulty easy-to-medium to encourage participation while still testing fundamental knowledge.

## 2. Second Year (SY) - Target: 400 Questions
* **Focus:** Core Computer Science Fundamentals.
* **Topics:**
  * Programming: C and C++ deeply
  * Data Structures: Arrays, Linked Lists, Stacks, Queues, Trees
  * OOP Concepts: Inheritance, Polymorphism, Encapsulation, Abstraction
  * Architecture: Microprocessor basics (8085/8086 architecture)
  * System: Operating System fundamentals (Scheduling, Deadlocks, Memory Management)

## 3. Third Year (TY) - Target: 400 Questions
* **Focus:** Advanced Application Development.
* **Topics:**
  * SY Syllabus Review (Minor priority)
  * Java Core: Multithreading, Collections Framework, Exception Handling
  * Advanced Java: Java Servlets, JSP, JDBC
  * Advanced OOP & C++ paradigms
  * Advanced DSA (Graphs, Dynamic Programming, Greedy Algorithms)

## 4. Final Year (LY) - Target: 300 Questions
* **Focus:** Industry Readiness & System Design.
* **Topics:**
  * All CS Related Topics
  * System Design (Load balancing, Caching, Scaling)
  * Microservices Architecture
  * Cloud Computing Fundamentals (AWS/GCP/Azure basics)
  * Advanced Databases (NoSQL, Indexing, Sharding)
  * Machine Learning & AI Basics
